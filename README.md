# Agent 工作流设计师

一个可用于**任何 AI Agent 产品**的提示词工作流，通过顾问式结构化访谈，帮助用户发现自己工作中适合接入 AI Agent 的场景，并生成一份视觉美观的 HTML 专属诊断报告。

适用于 Claude、Claude Code、Codex、OpenClaw、Hermes 等任何支持自定义 System Prompt 或 Agent 指令的产品。

## 这个提示词做什么

它不是告诉你"可以用 AI 提高效率"，而是：

1. 先了解你的职业、日常工作流程和真实痛点
2. 找出哪些任务**值得自动化**、哪些适合 AI **辅助**、哪些**暂不建议**自动化
3. 为每个场景设计具体可落地的 Agent 工作流（含输入、执行步骤、输出、人工审核点）
4. 输出一份**完整的 HTML 网页报告**，包含 7 天启动计划和 30 天升级路线

整个访谈采用**单问单答**的顾问方式，每次只问 1 个问题，不会把你淹没在表单里。

---

## 使用方法

打开 `SKILL.md`，找到第 20 节「可直接复制的启动提示词」，将其内容复制后：

- **对话产品**（Claude、ChatGPT 等）：直接粘贴到对话框发送，AI 会立即开始诊断访谈
- **有 System Prompt 的产品**：粘贴到 System Prompt 配置区，用户打开对话即自动启动
- **Agent 平台**（Dify、Coze、FastGPT 等）：粘贴到 Agent 指令区，配置成独立应用

启动后，AI 会以顾问身份开始单问单答的访谈，全程大约 10–15 分钟。

---

## 访谈流程

```
使用目的确认
    ↓
职业画像采集（职业、目标、产出物、受众）
    ↓
工作流程拆解（把工作拆成完整流程地图）
    ↓
痛点与重复任务识别
    ↓
自动化机会分析（A 优先 / B 辅助 / C 暂不建议）
    ↓
Agent 工作流设计（含输入、步骤、输出、审核点）
    ↓
优先级排序 + 落地路线图
    ↓
生成完整 HTML 诊断报告
```

## 报告包含哪些内容

| 模块 | 内容 |
|------|------|
| Hero 封面 | 用户画像摘要和核心诊断指标 |
| 工作画像卡片 | 职业类型、受众、表达风格、当前痛点 |
| 流程地图 | 完整工作流拆解，标注改造潜力 |
| Agent 机会总览 | 可自动化 / 辅助 / 暂不建议 的任务清单 |
| 推荐 Agent 工作流 | 3 条具体工作流，含输入、执行步骤、输出、审核点、自动化等级 |
| 优先级排序 | 按投入产出比排好先后顺序 |
| 7 天启动计划 | 立刻可执行的第一周行动 |
| 30 天升级路线 | 从 AI 辅助到 Agent 化的完整路径 |
| 最终建议 | 一句话核心结论 |

## 自动化等级说明

| 等级 | 说明 | 适合阶段 |
|------|------|----------|
| L1 | AI 辅助型：单步任务，生成初稿 | 入门 |
| L2 | 流程半自动型：多步骤串联，关键节点人工审核 | 大多数用户的第一阶段 |
| L3 | 多工具 Agent：跨工具调用 | 有明确工作流时 |
| L4 | 自动触发型：定时或事件驱动 | 成熟工作流 |
| L5 | 自主执行型：自主计划与执行 | 边界清晰的受控场景 |

## 设计原则

- **从用户工作出发，不从工具出发** — 先理解真实流程，再判断哪里适合 AI 介入
- **先半自动，再全自动** — Agent 做初稿，用户做决策
- **每条建议都落到具体工作流** — 不输出空泛结论
- **明确告诉用户哪些不适合自动化** — 不是所有任务都值得交给 Agent
- **最终输出 HTML 报告** — 让用户拿到一份顾问级专属诊断，而不是一段聊天记录
